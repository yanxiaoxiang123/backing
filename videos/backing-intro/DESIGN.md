# Backing · 60 秒项目介绍

模式：自主自由创作。用户已授权自行决定；用途为项目介绍；60 秒。1920×1080、30fps、1800帧。中文标题与字幕，配乐与克制的拟音，无配音。

## 视觉与动效
备选：A 浅灰研究终端（选中）；B 暗色交易室（拒绝，偏离页面）；C Ink Press（拒绝固定叙事与暖纸）。
底色 #F6F6F6，侧栏 #F0F0F0，面板 #FCFCFC；字 #242424、次字 #6B6B6B；品牌 #1B6E66；图表蓝 #1677FF、预测红 #FF4545。无暖金、霓虹、重阴影和随机手持。
字体复用项目中文无衬线 Microsoft YaHei/PingFang SC，英文 Arial/Geist；数字等宽。标题 90–140px，叙事字幕64px、辅助36px；画面安全边距96px。实际截图以2x采集，关键面板4x。
主运动：专业信赖、无持续弹动；21帧 ease-out 入场，相机过渡36–60帧，镜头收尾≥30帧静止。落地隐喻使用参考卡微过冲；全画面节拍冲击0次。
选择性适配：不使用 spotlight 的暗场舞台；主体为明亮页面，拒绝为套卡改黑。品牌卡保留字标压印与hold；文档卡保留真实版式遮罩书写与完整双栏；行卡保留12帧飞行/16°收平/真实槽位；结尾保留四方组装与crane，不用金尘或金色灯光。

## 音乐及最终帧界限
配乐选 House Vibez / Lily J（Mixkit），122.00 BPM，实测相位 0.0892s。全曲网格最大残差22.7ms，故不声称精确固定网格；切点使用最近的实际检测拍点（180 / 416 / 667 / 903 / 1197 / 1464 / 1626），总长仍为1800帧。相机无逐拍冲击。BGM由原曲裁60秒并作首尾淡化。
音源为本项目从Freesound取得的CC0预览文件，来源及衍生处理写入audio-manifest.json。录音素材未以测量替代听感结论，最终做响度与同步客观验证。
首个AAC探针交叉相关测得输出整体滞后1.27帧，音源自身峰值另计，所有短SFX起点通过统一align()补偿。
最终标题为人工断行，每行最多6个汉字，72px；主字幕64px、演示声明36px。

## 独立审查后的精修
检索使用真实筛选后的页面纹理与按钮坐标，数量和命中一致；AI 列表 marker 连同文字遮罩，增加响应式真实正文的可读特写再回到三栏。回测过滤零高测量行，让五条记录完整入场。八镜标题字号接入工作台，品牌、架构和结尾强调色接入组件。AI 副文案收窄为本镜实际呈现的研究依据与风险边界，不暗示已展示工具执行。维持原有1800帧、全部音效与拍点。
