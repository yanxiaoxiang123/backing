隐私说明

本页说明 Backing 的公开介绍页和登录后系统分别处理哪些数据。

公开介绍页

介绍页不加载统计脚本，不设置 Cookie，不收集访客个人信息。

登录后的系统

  • 使用 API Key 换取 8 小时的 HttpOnly 会话 Cookie。
  • 状态变更请求使用 CSRF Cookie 做双提交校验。
  • API Key 不写入 localStorage，也不进入浏览器 bundle。
  • 数据存储在部署者配置的 SQLite 或 MySQL 中。

第三方服务

系统可能调用 baostock、mootdx 和 DeepSeek 获取行情、K 线或分析结果；具体请求由部署者配置。

联系

如对数据处理有疑问，请联系部署该系统的管理员。
