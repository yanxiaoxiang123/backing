# Agent 会话 AI 标题

最近会话过去只有前端临时截取的标题，刷新列表后被后端的空标题覆盖。
现在标题由后端生成并持久化到 `agent_chat_threads.title`。

- native 模式复用 `DEEPSEEK_API_KEY`、`DEEPSEEK_BASE_URL`、`DEEPSEEK_MODEL`；
  无新配置、依赖或数据库迁移。fake 模式不请求真实模型。
- 首次提交消息后，在独立的单线程后台任务中概括首条消息，建议 8–16 字，
  最多 36 字。请求超时 12 秒、不重试、限制输出 token，且不调用聊天工具。
- 打开最近列表或会话详情时，会自动排队补全有消息的空标题或旧默认标题。
  同一会话的并发请求合并为一次命名，最多排队 200 个任务。
- 已有有效标题、空会话、归档会话不调用 AI。生成期间若标题被其他操作修改，
  或会话已归档，结果不会覆盖它。补名不修改最近活动时间，不打乱列表顺序。
- AI 出错或返回空标题时，将首条消息的单行摘要保存为备用标题；
  后续刷新不重复请求 AI，聊天运行和消息事件不受命名结果影响。
- 列表/详情响应新增 `title_pending`。前端在后台命名期间约每 2 秒串行刷新，
  同时更新最近列表和当前会话标题；标题保存后停止轮询。
- 命名任务队列仅存在于进程内，重启后由后续列表/详情读取重新排队；
  已保存的标题保留在数据库中。

相关实现：`backend/app/agent_chat/titles.py`、`service.py`、`stores.py`、
`api.py`、`frontend/src/hooks/useAgentChat.ts`。
