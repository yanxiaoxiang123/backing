# 10 告警系统

**交付**：信号漂移、数据延迟、provider 失败、成本、回撤超阈五类告警；落库 + SSE 事件 + 工作台面板；阈值可配置。

**范围**：
- 告警表（关联 run/数据事件）；阈值配置（配置表/环境变量，默认值可覆盖）。
- 生成点：撮合循环与数据服务检查（回撤超阈、数据陈旧、provider 失败、费用异常、信号漂移）。
- SSE：新告警事件种类；工作台告警面板（列表 + 已读状态）。
- 每条告警可关联 run 与触发数据事件。

**验收**：
- pytest：五类触发条件、阈值覆盖、去重/已读状态、SSE 事件。
- Vitest：告警面板渲染；`npm run build` 全绿。

**阻塞**：03, 05
**委派**：ineligible（跨 SSE/前端/配置耦合）
