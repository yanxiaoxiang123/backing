# 03 模拟盘持久化 + 撮合纯函数 + 重放

**交付**：模拟盘账户/持仓/订单/成交/资金流水五张 append-only 事件表 + Alembic 迁移 + repository；确定性撮合纯函数；事件重放审计函数。

**范围**：
- 撮合规则（规格决策 21）：日线粒度，成交价 = 审批通过后下一交易日开盘价；T+1；买卖 100 股整数倍（清仓残余零股一次卖出）；一字板不成交（开盘==最高==最低==涨跌停价）；停牌顺延但审批有效期不延；限价约束（买单开 ≤ 限价、卖单开 ≥ 限价）；涨跌停幅度主板 10%、创业/科创 20%、ST 按名称前缀识别默认主板。
- 费用：佣金 0.025%（min 5 元，双边）+ 卖出印花税 0.05% + 过户费 0.001%（双边）。
- 事件 append-only：订单/成交/流水带 run_id/step/tool_call/approval 引用与 seq；重放函数从事件重建账户与现状比对一致。
- 默认单模拟盘账户，初始虚拟资金可配置。

**验收**：
- pytest：T+1、整手、零股清仓、一字板不成交、停牌顺延、限价、费用明细、TTL 过期、重放一致性，逐一覆盖。
- 迁移 upgrade↔downgrade 往返通过。

**阻塞**：None
**委派**：ineligible（共享 models/migrations 耦合）
