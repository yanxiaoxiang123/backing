# 09 盘前计划 / 盘后归因

**交付**：盘前计划视图（目标/股票池/待批订单）；盘后归因报告：模拟盘相对 sh.000300 基准的收益分解纯函数 + API + 工作台面板。

**范围**：
- 归因纯函数：每日组合收益 vs 基准收益，分解超额收益/暴露/费用拖累，确定性测试样例。
- API：某日期范围归因报告；盘前计划快照（基于 RunPlan 与待批订单）。
- 工作台：归因面板（数字 + 图表），计划与执行差异可审计（订单 vs 成交对照）。

**验收**：
- pytest：归因分解纯函数确定性样例；API 响应 schema。
- Vitest：归因面板渲染；`npm run build` 全绿。

**阻塞**：03
**委派**：ineligible（跨前后端+API 耦合）
