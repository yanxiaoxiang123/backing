# 12 模拟盘 E2E 集成 + 后台连跑启动 + 恢复演练 + runbook

**交付**：研究→策略→回测→paper 提议→审批→撮合→归因→告警黄金路径 E2E；后台 soak 引擎启动；杀进程→重启恢复演练 100%；订单重放审计工具；4–8 周验收 runbook。

**范围**：
- E2E 黄金路径脚本/手动演示：一个 run 全链路走通，产生订单→批准→下一交易日撮合成交→归因报告→（触发条件时）告警。
- 后台连跑：soak 引擎作为后台任务启动并持续运行，交付时报告累计运行时长与事件数。
- 恢复演练：杀进程→重启→恢复成功率 100%（脚本输出证据）。
- 重放审计：工具从订单/成交/流水事件重建账户，与现状比对一致（demo + 测试）。
- runbook：`docs/` 下 4–8 周连续运行验收清单（每日/每周检查项、恢复与审计操作、验收判据）。

**验收**：
- E2E 走通证据（脚本输出或手动记录）。
- 恢复演练 100% 输出；重放比对一致。
- 后台任务存活状态 + runbook 文档落盘。
