# Redis 缓存与统一行情优化实施记录

本文件是 `codex/frontend-research-terminal` 分支上 Redis 缓存与统一行情优化的实施事实源。

## 目标

- 为当前行情、研究数据和技术指标提供可降级的内存/Redis 缓存。
- 统一个股页、仪表盘、自选和 Agent 使用的当前行情来源。
- K 线首次读取完整快照，后续只读取尾部增量；同一标的和周期在进程内共享轮询。
- Redis 不可用时继续工作，Mootdx 故障时保留最近成功数据并显式标记新鲜度。
