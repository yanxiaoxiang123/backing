# 12 端到端评测门禁

- **用户可见交付**：10 个 golden cases 在新运行时上跑通并出确定性分数与 trace 指标（证据覆盖率、引用正确率、计划完成率、恢复成功率、成本与 P95 延迟字段）；P2 验收演示脚本：自然语言目标 → `RunPlan` → 专家执行 → 确定性回测 → 通过/拒绝及原因。
- **验收标准**：
  1. 缓存回放下 10 case 全跑通，分数可重复；live 跑批开关可用（默认关）。
  2. 恢复成功率用例：注入中断 → 恢复后完成，计为 100%。
  3. 无前视检查 100% 通过（含财报发布/解禁时点用例）。
  4. 关键结论引用覆盖率 ≥95%（以 source_id/tool_call 关联计算）。
  5. 验收演示产出 JSON 报告 + 一个可复现命令；单次标准研究成本与 P95 耗时可配置且可见。
- **阻塞任务**：03, 07, 09
- **委派**：ineligible（全局耦合，主 agent 执行）
