# 10 前端三栏工作台

- **用户可见交付**：路由 `/workspace` 的 Agent 工作台：左侧导航、中间对话与运行计划（持续对话、`run_id`、节点进度、追问输入框）、右侧研究区「行情与结论/证据/回测/风险」四页签；工具调用为可折叠 timeline；高风险操作显示审批卡；加载/部分失败/数据为空/等待审批/已取消/恢复中独立状态。
- **验收标准**：
  1. SSE 客户端支持断线重连与 `Last-Event-ID` 恢复；组件只消费结构化事件，不解析自然语言 HTML。
  2. 对话中"查看证据/回测/风险"只切页签不跳页；参数修改产生新 run，旧回测不被覆盖。
  3. Vitest：事件流渲染、四页签切换、审批卡、各状态机分支。
  4. `npm run build` 全绿；工作台路由懒加载，主 bundle 体积不显著恶化。
  5. 复用 antd/ECharts 与既有股票详情组件。
- **阻塞任务**：06
- **委派**：eligible（独立前端纵向切片；需在 prompt 中给出 SSE 事件契约与既有组件清单）
