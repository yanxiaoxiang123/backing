# Agent Harness 统一运行时规格 v2 — P2 收尾 + P3 模拟盘实现

> 日期：2026-08-15
> 上游依据：`AGENT_QUANT_UPGRADE_PLAN.md`（2026-08-14）、规格 v1 `docs/specs/2026-08-15-agent-harness-runtime.md`（已批准）

> 决策记录：v1 决策 1–16 全部保持有效；本规格新增决策 17–22（grilling 已由用户确认）。

## 1. 问题陈述

v1 已交付 P0–P2 核心（统一 runtime、工具网关、工作台、评测骨架），但存在四个延期项与一个未实现阶段：

1. **引用覆盖率 ≥95% 未达标**：研究专家只有行情/因子确定性工具，没有新闻/公告/财报工具，实测引用覆盖率 0.1–0.5。
2. **TradingAgents 未成为研究引擎**：facade 就绪但未深接线，其 7 类分析师与辩论能力未被统一运行时复用。
3. **前端参数编辑缺失**：工作台无法修改策略参数发起新 run。
4. **artifact 工作区未写产物**：表/端点就绪，但运行时节点不产出可查看的工作区文件。
5. **DSH 运行时未装配**：只有 HTTP 直连 POC 骨架，独立 UI、工具审批、session↔run 映射未端到端打通。
6. **Phase 3 模拟盘未实现**：paper broker、审批落地、盘前计划/盘后归因、告警、持续运行验证均只有规划文档。

目标：补齐上述全部延期项，并把模拟盘闭环做成可执行层——「研究 → 回测 → 审计 → 风控 → 人工批准 → 模拟执行 → 归因」，且每一笔模拟成交都可重放、可解释、可审计。仍不接入实盘。

## 2. 用户可见的解决方案

1. **真实研究专家**：研究专家可用确定性新闻/公告/财报/指数工具（akshare + baostock，SQLite 缓存），每条结论带 `source_id/as_of/vendor/data_version`；golden 评测引用覆盖率 ≥95%。
2. **深度研究引擎**：Supervisor 在需要多分析师研究时将 TradingAgents 图作为子图运行，其全部取数经新增 gateway vendor 走类型化工具网关（权限分级、证据 envelope、tool_call 落库），产出归一为结构化 claims 与 artifacts。
3. **参数编辑即新 run**：工作台回测页签可编辑策略参数并提交新 run；每次 run 生成新 `run_id`，旧回测/产物永不覆盖。
4. **artifact 工作区**：运行时节点把策略规格、回测报告、研究摘要等写成每 run 独立的工作区文件，工作台可直接查看/下载。
5. **DSH 对话入口**：从固定 commit 克隆构建 DSH runtime（仅构建产物，不改源），装配 quant.gateway 工具消费者、独立 UI 与工具审批卡，`session_id ↔ run_id` 映射端到端可恢复。
6. **模拟盘闭环**：模拟盘账户/持仓/订单事件（append-only，可重放）；订单必须经确定性风控校验 + 人工审批（一次性撮合窗口有效）后进入模拟盘；盘前计划、盘后归因（对 sh.000300 基准分解）、告警（SSE + 面板 + 落库）；持续运行 soak 器 + 恢复演练 + 订单重放审计 + 4–8 周验收 runbook。

## 3. 用户故事 / 行为

### Phase 2 收尾

- **US-2.6** 作为研究者，研究专家可以检索某股票的新闻、公告与财报摘要，并引用它们支持结论；每条引用必须携带证据五元组，无法获得证据的表述必须标记 `hypothesis=True`；golden cases（缓存回放）下引用覆盖率 ≥95%。
- **US-2.7** 作为用户，对需要深度研究的 run，Supervisor 会调度 TradingAgents 的多分析师子图；子图内所有数据访问都经类型化工具网关（有权限校验、证据 envelope、tool_call 记录），其研究报告以 artifact 与结构化 claims 落地；网关没有对应能力的数据请求必须显式失败（"未接入"），不得绕开网关直连数据源。
- **US-2.8** 作为用户，我在工作台回测页签修改策略参数（如均线窗口、股票池）后提交，系统创建新 `run_id` 重新执行；旧 run 的回测与产物保持原样可查。
- **US-2.9** 作为审计者，运行时节点产出的关键产物（策略规格、回测报告、研究摘要）同时落为每 run 独立工作区文件与 artifacts 记录，工作台可查看/下载，且文件内容与记录一致。
- **US-2.10** 作为用户，我可以通过 DSH 独立 UI 与量化工具对话；工具调用出现审批卡（展示参数与风险），批准后执行；对话 `session_id` 与后端 `run_id` 双向可查可恢复。

### Phase 3 模拟盘（本轮实现）

- **US-3.1** 作为用户，Agent 可以提议模拟盘订单（`execution.paper.*`），系统按 A 股规则确定性撮合：日线粒度、审批通过后的下一交易日开盘价成交；T+1（当日买入次日才可卖）、买卖为 100 股整数倍（清仓残余零股一次卖出）、一字涨跌停/停牌不成交；费用为佣金 0.025%（最低 5 元，双边）+ 卖出印花税 0.05% + 过户费 0.001%（双边）。每笔订单/成交是 append-only 事件，关联 run_id/step/tool_call/approval，可从头重放重建账户。
- **US-3.2** 作为审批人，我在工作台审批卡上看到订单方向、目标仓位、触发条件、风险摘要与有效期，批准/拒绝后订单进入相应状态；审批在下一次撮合窗口（下一交易日开盘）一次性有效，用后或窗口过期即 `expired`，再下单需重新审批；无审批的订单绝不成交。
- **US-3.3** 作为研究者，我可以查看盘前计划（目标、股票池、待批订单）与盘后归因报告：模拟盘相对基准（sh.000300）的收益分解（超额收益、暴露、费用拖累），计划与执行差异可审计。
- **US-3.4** 作为运维者，信号漂移、数据延迟、provider 失败、成本、回撤超阈会产生告警：每条告警落库并关联 run/数据事件，通过 SSE 推送并在工作台面板展示，阈值可配置。
- **US-3.5** 作为维护者，模拟盘引擎可以后台持续运行（soak）；进程被杀/重启后恢复成功率 100%；每笔订单可用重放工具复现并解释；4–8 周连续运行验收按 runbook 清单执行。

### Phase 4（仍仅附录）

- 实盘连接、券商接口、合规评审清单维持 v1 附录范围，本规格不扩展。

## 4. 实施决策与约束（新增，v1 决策 1–16 保持有效）

### 研究数据层

17. **确定性证据层**：新增新闻/公告/财报/基准指数数据服务，数据源为 akshare（新闻、公告、财报摘要）与 baostock（指数日线，如 sh.000300）；结果落 SQLite 缓存表，缓存条目携带 `source_id/as_of/vendor/data_version`；运行时优先读缓存、缓存失效才外呼；评测只走缓存回放，不依赖外网与 API key。
18. **LLM 角色**：研究专家中的 LLM 只做工具选择、检索参数与结论解释；任何事实必须来自工具 envelope，禁止 LLM 凭空陈述事实；无证据表述必须 `hypothesis=True`。

### TradingAgents 深接线

19. **子图 + gateway vendor**：TradingAgents 图作为 Supervisor 的深度研究子图运行（同一进程、同一 LangGraph 运行时），复用现有 checkpoint 与预算边界；在其 vendor 路由层新增 `gateway` vendor，把各分析师的数据方法映射到类型化工具网关（in-process 调用 Tool Registry，构建 ToolContext 带 db session），调用被记录为 tool_call；gateway 模式下未映射的方法显式返回"未接入"错误，禁止回退到直连 vendor。
20. **产出归一**：子图研究报告归一为 `ResearchClaim` 列表 + 报告 artifact；子图内部步骤作为 run 的 step 可见；辩论/多空结论保留为结构化字段而非自由文本。

### 模拟盘

21. **确定性撮合**：撮合纯函数输入（订单、日线序列、规则参数）输出（成交/顺延/拒绝 + 费用明细），无随机、无实时行情；成交价 = 审批通过后下一交易日开盘价；订单限价约束（买单开盘价 ≤ 限价、卖单开盘价 ≥ 限价）；一字板判定 = 开盘 == 最高 == 最低 == 涨跌停价（买盘在涨停板不成交、卖盘在跌停板不成交）；停牌（当日无 bar）顺延但审批有效期不延，窗口过后订单 `expired`；涨跌停幅度按板块（主板 10%、创业板/科创板 20%），ST 按名称前缀识别（默认主板规则）。
22. **审批一次性有效**：审批批准后只对下一个撮合窗口有效，用后失效；拒绝/过期/失效订单不得成交，重新下单需重新审批；审批状态机 `pending → approved/rejected`，窗口过后 `approved → expired`，成交后 `approved → used`。
23. **账户与事件**：默认单模拟盘账户（初始虚拟资金可配置）；订单/成交/资金流水为 append-only 事件表；重放函数从事件序列重建持仓/现金，与当前状态比对一致（审计测试）。
24. **归因与告警**：归因是纯函数（每日组合收益 vs 基准收益分解），确定性测试覆盖；告警为落库事件 + SSE 事件种类 + 工作台面板，阈值存配置（环境变量/配置表），默认值可覆盖。

### DSH 装配

25. **构建边界**：在未跟踪的 `deepseek-harness/` 克隆内执行 pnpm install/build 与 `pip install -e`（仅生成构建产物与 egg-info，均在其 .gitignore 内），不改任何源文件；克隆保持未跟踪、不进主仓历史；DSH 固定 commit 47f9438。
26. **插件形态**：`dsh-quant-plugin/` 提供 quant.gateway Cordis 工具消费者（走 FastAPI Tool Gateway，带现有认证）、独立 UI 配置与 session↔run 映射；DSH 管对话轮次预算，LangGraph 管量化预算（v1 开放问题按此分界定案）。

### 认证与安全（沿用 v1 决策 13–15）

- 模拟盘/审批/告警端点沿用现有认证（session cookie / X-API-Key）与 CSRF 约定；`execution.paper.*` 工具权限 = 需人工审批；Agent 不获得数据库写权限、生产 Shell 或任意代码执行。

## 5. 测试接缝与成功标准

| 层 | 接缝 | 验证方式 |
|---|---|---|
| 研究数据层 | 新闻/公告/财报/指数服务 + 缓存 | pytest：缓存命中/失效、证据五元组、外呼 mock、评测缓存回放 |
| 研究专家 | claims + 引用 | golden cases 缓存回放：引用覆盖率 ≥95%、无证据即 hypothesis、无前视 |
| TA 子图 | gateway vendor 适配器 | pytest：映射方法经网关、权限拒绝、未映射方法显式失败、无直连回退；子图 run 产出 claims/artifact |
| 参数编辑 | 前端编辑 → 新 run | Vitest：提交生成新 run_id、旧产物不变；`npm run build` 全绿 |
| artifact 工作区 | 节点写文件 + 记录 | pytest：文件与记录一致、可列表/下载 |
| DSH | 构建产物 + 网关对话 | 构建后运行时启动 smoke；工具审批卡 E2E（脚本化探针 + 手动验收） |
| 模拟盘撮合 | 撮合纯函数 | pytest：T+1、整手、零股清仓、一字板不成交、停牌顺延、限价、费用、TTL 过期 |
| 审批 | 状态机 | pytest：pending→approved/rejected/expired/used；无审批不成交 |
| 重放审计 | 事件重放 | pytest：从事件重建账户与现状一致 |
| 归因 | 纯函数分解 | pytest：确定性样例 |
| 告警 | 阈值 + SSE | pytest：触发条件、可配置、事件推送 |
| 持续运行 | soak + 恢复演练 | 后台引擎启动证据；杀进程→重启→恢复成功率 100% 演练脚本输出 |

**阶段完成标准（验收门槛）**

- **P2 收尾**：引用覆盖率 ≥95%（缓存回放证据）；TA 子图全部取数经网关（测试证明无直连）；参数编辑产生新 run 且旧产物不可变；artifact 工作区文件与记录一致；DSH 运行时从构建产物启动、审批 E2E 通过。
- **P3**：撮合/审批/重放/归因/告警测试全绿；模拟盘引擎后台连跑（交付时报告累计运行与事件数）；恢复演练 100%；重放审计工具可用；4–8 周验收 runbook 交付。
- **回归底线**：后端既有 291 测试 + 前端 42 测试与 build 保持全绿；`ruff check` 干净；迁移 upgrade↔downgrade 往返通过；golden cases 缓存回放全通过。

## 7. 风险与开放问题

1. **akshare 新闻接口网络脆弱性/接口变更**：测试全 mock/stub；运行时失败计入 run 错误事件与 `DataQualityReport`；缓存兜底（缓存过期前不阻断）。
2. **TradingAgents 与 langchain 1.5.4 差异**：兼容性 smoke 已过（3/3 checkpoint resume）；深接线时逐方法验证，未映射方法显式"未接入"；若子图在统一运行时出现不可调和冲突，回退为进程内独立执行 + 网关适配（结论带回评审）。
3. **DSH 构建可复现性**：固定 commit + pnpm lock；构建失败则维持 HTTP 直连降级并记录（同 v1 决策）。
4. **SQLite 并发**：web 服务与后台模拟盘引擎共用库，需 WAL 与重试策略，测试覆盖并发写。
5. **一字板判定近似**：以开盘==最高==最低==涨跌停价近似，未接 L2 盘口；在规格内文档化。
6. **开放问题**：告警默认阈值（回撤/数据延迟）初始值需在实现时定稿；模拟盘初始资金默认值；DSH 对话预算与 LangGraph 预算的分界在装配联调时验证（决策 26 已定分界，联调确认）。
