# 第二轮：研究入口与告警定位

日期：2026-11-14

## 目标

从当前页面打开副驾驶并进入完整工作台时，继续同一个会话并保留股票；从告警入口进入时，直接看到告警及所点记录。加载失败不能伪装成没有告警。

用户要求“继续进行第二轮”，此前已将诊断与优化取舍交由实现方判断。本轮范围及下列具体交互是实现方选择，不表述为用户逐项批准。

## 范围与行为

1. 副驾驶到工作台的链接明确携带当前 `thread_id` 与合法股票 `stock`。没有会话时只带股票，不创建会话、不发送请求。不携带来源页面无关参数或提示词。
2. 全局副驾驶读取个股路由或当前页面 `stock` 查询参数；仅使用现有 PageContext 的 route/entity 字段，不扩展模型/后端数据契约。
3. 工作台研究页签由 `panel` 查询参数驱动，允许 market/evidence/backtest/risk/artifacts/attribution/alerts。未知值回退行情；`alert` 为正安全整数时定位告警。页签切换保留会话、股票及其他参数，支持刷新与浏览器前进后退。
4. 显式面板入口会展开桌面研究区或打开手机/平板抽屉，之后仍可正常关闭或折叠。告警记录进入可视区域并有“当前告警”标识；ID 不在返回列表时明确说明未找到，仍展示可用列表。
5. 仪表盘告警条目携带告警 ID；查看全部告警与侧栏未读告警直达告警面板。现有任务计数不是任务列表，本轮不新增任务中心。
6. 告警面板提供初次加载、空列表、错误重试、刷新和标记已读状态。刷新失败保留已有记录并显示错误；已读失败保留未读及重试入口。成功后刷新全局告警计数。打开面板不自动标记已读。
7. 工作台已打开时，经副驾驶选择另一会话进入也必须显示正确会话；对话 URL 同步需与面板 URL 同步兼容，不丢参数或浏览器历史状态。

## 实现选择与限制

- 沿用 React Router、AntD、TanStack Query 及现有接口，前端实现，不新增依赖。
- 在当前 feature checkout 继续，保留首轮及用户其他未提交工作，不提交、推送、部署。
- 沿用现有视觉体系，仅增加定位标识和错误/操作反馈，不重做导航或图表。
- 仅向已有登录会话接口请求数据；浏览器验证使用测试夹具，不调用真实模型、行情供应商或模拟下单。
- 告警 API 仍返回其现有范围；不宣称实现后端分页或全历史搜索。
- 未发送的输入草稿跨副驾驶/工作台迁移不在本轮范围；交接的是已创建会话与标的。

## 验收

- 从策略页带股票打开副驾驶，向工作台交接后 URL、聊天内容、股票一致，刷新可恢复，交接不产生额外 POST。
- 已在工作台时交接/前进后退切换会话不串内容。
- 仪表盘告警、侧栏告警在桌面折叠状态和手机端都能直接看到告警；关闭后可再打开。
- 面板切换保留 thread_id 和其他参数；非法面板、非法/缺失告警 ID 安全回退。
- 告警读取/标记失败均可恢复，不清空已有证据、不显示虚假的已读状态。
