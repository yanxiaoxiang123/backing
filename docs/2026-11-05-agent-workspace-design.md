# Agent 工作台界面优化

日期：2026-11-05。

## 设计方向

采用 `design-taste-frontend` 的应用界面流程，方向为 **Achromatic ledger**，seed **46279591**。未重抽方向，保留项目已有的浅色、墨色与深青色语义。

工作台首先回答：**我正在研究什么，下一步如何验证？**

主区域是一张可持续阅读与书写的研究页。会话列表负责定位记录，研究面板负责核对行情、证据、回测与风险。桌面保留三栏，窄桌面与平板将研究面板收进抽屉，手机将会话列表也收进抽屉。

本产品的特征是会话、股票标的和量化研究结果之间的关联。保留中文系统字体；Windows 优先使用本机 Microsoft YaHei，不引入网络字体。红涨绿跌继续遵循项目既有的 A 股价格语义。

## 主要变化

| 项目 | 优化前 | 优化后 |
| --- | --- | --- |
| 页面标题 | 视觉隐藏的 h1，10px 英文标签反而占据标题位置 | 20px 可见标题，中文会话与研究标题 |
| 桌面比例 | 多代最小宽度叠加，研究区挤压聊天区 | 200px 会话列表、弹性聊天区、320px 研究区 |
| 手机 | 会话列表常驻，聊天与输入空间被挤压 | 全宽聊天，会话与研究分别通过抽屉访问 |
| 空会话 | 通用插画与一行说明 | 3 个可编辑的研究问题示例 |
| 研究空态 | 信息提示和第二张通用空插画 | 等待研究标的，说明行情、证据与验证内容 |
| 写作区 | 单行气泡，发送操作不明显 | 两行起步的输入区、发送按钮与快捷键说明 |
| 研究元信息 | run_id、快照编号直接展开 | 默认展示研究目标，编号放进“研究记录”详情 |
| 行情 | 单独的 K 线图 | 股票标的、最新收盘价、对比上一条收盘价的涨跌幅及数据日期 |
| 视觉层次 | 重阴影、蓝色选中块、小号英文标签 | 平面布局、中性色选中态、统一边界和间距 |

研究示例只填入草稿并聚焦输入框，等待用户编辑、确认后才发送，不会自动调用模型。

## 保留与修复

- 保留会话选择、新建、归档、历史消息、流式回复、停止生成、Markdown、思考过程和工具调用。
- 保留行情目标跟随当前会话、旧请求防串标、研究关联、证据、回测参数调整、风险审批、产物、归因和告警。
- 保留桌面侧栏折叠偏好，窄屏使用 AntD Drawer 管理遮罩、Escape 关闭与焦点返回。
- 会话选择和归档使用相邻的独立按钮，避免在可点击容器中嵌套另一项交互。
- 修复中文输入法确认候选词时被 Enter 提前发送的问题。
- 修复 React StrictMode 重复挂载时，URL 会话恢复目标提前被清空的问题；增加了对应的 hook 与浏览器刷新回归测试。
- 合并旧工作台和聊天样式中的重复覆盖；未更换框架或新增依赖。

### ROUND 0

Seen in one second: 两层侧栏和多块相似的空区域，难以看出主要操作。

Idea (one sentence): 量化研究应沿着会话展开，行情与验证结果负责支撑判断。

Live thing: 输入研究问题、切换会话、查看关联研究。

Layout words by section: shell=侧栏 / history=列表 / conversation=空插画 / research=重复空态。

Scores: design 4.5 · usability 4.0 · creativity 5.0 · content 6.0 → overall 4.6。

Caps applied: 应用界面规则，不使用营销页面的摄影和动画数量限制。

Top three problems:

1. 手机聊天区被常驻会话列表挤压，标题与输入区受限；改为抽屉。
2. 聊天与研究区权重接近，主要操作没有焦点；扩大聊天区并缩减辅助栏。
3. 小号英文标签、重阴影与两处空插画制造噪声；替换为可见标题、问题示例与真实状态。

3. 空状态没有编造行情或研究结论；截图中的市场数据仅来自隔离的测试 fixture。
