# Agent 工作台层次、正文显现与复制反馈

沿用现有 Achromatic ledger（seed 46279591）、中文系统字体和灰色/深青色体系，
按用户指定的层级与动效细化，未重新抽取布局或更换组件库。

## 背景与排版

- 侧栏 `#f0f0f0`、主区 `#f6f6f6`、卡片 `#fcfcfc`；
  相邻层级的 RGB 灰阶相差 6/255，约 2.35%。
- 全局侧栏和研究会话侧栏使用最深一级；正文、研究主区使用第二级；
  回复、输入、选中的会话与研究卡片使用最浅一级。
- 移除工作台外框、面板分隔边框、新会话按钮、提示卡与输入框的常驻边框。
  保留键盘聚焦轮廓和数据表格中的轻分隔，避免失去可操作性与行对齐。
- 会话标题可显示两行。中文正文与会话标题的末尾两个汉字及结尾标点保持在一起，
  配合 `text-wrap: pretty` 和严格中文断行，避免末行只留单字。
- 数字使用 `lining-nums tabular-nums`。回复与表格撑满可用宽度，
  宽表在独立容器内横向滚动，页面不横向溢出。
- 正文行内图片/图标下移 `0.125em`，不改变工具栏中已经通过 flex 居中的图标。

## 正文与交互

- 新收到的正文以字素为单位做 180ms 的 `blur(2px) → blur(0)` 和透明度显现，
  通常相邻字错开 24ms，形成交叠的显现波。
- 快速或大批片段会压缩错峰间隔，限制延迟积累，不让回复落后服务器数秒。
  已显示的内容不从头重播；历史回复直接显示；代码块保持静态；
  英文单词与复合 emoji 保留正确分组。
- 动效完结后清除临时逐字节点。开启系统“减少动态效果”时直接清晰显示。
- 复制按钮复制完整原始 Markdown。点击提供轻微回弹，成功时弹出小对勾和“已复制”，
  2.5 秒后清除；再次复制会重新计时；权限失败不会显示成功。
- 聊天跟随滚动改为直接定位，避免流式片段持续触发平滑滚动；
  菜单与抽屉以约 180ms 收尾；K 线关闭插值动画，缩放/拖动即时更新。
- 用户明确要求的短暂文字模糊和复制回弹，是对设计技能默认“只用 transform/opacity”
  与“避免回弹”规则的局部覆盖；其他内容没有添加入场动画。
