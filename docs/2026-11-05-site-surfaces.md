# 全站微差灰阶、排版与动效统一

实施日期：2026-11-05。复用现有 React / Vite、Ant Design、ECharts，以及原有路由、认证、数据获取和业务状态。没有新增依赖、后端接口或数据库迁移。

## 共享视觉来源

- `frontend/public/ui-tokens.css`：三层底色分别为 `#F0F0F0`、`#F6F6F6`、`#FCFCFC`，相邻差值为 `6/255 ≈ 2.35%`。同时定义文字、分隔线、品牌色、缓动及 120 / 160 / 180ms 的节奏。
- `frontend/index.html`、欢迎页和法律页面的 HTML：在页面样式与脚本执行前加载共享变量。
- `frontend/src/styles/uiTheme.ts`、`main.tsx`、`researchTheme.ts`：从已加载的 CSS 读取 Ant Design 主题，覆盖挂载到 body 的下拉、弹窗、抽屉、日期面板与提示层。
- `tokens.css`、`surfaces.css` 及各页面样式：用背景差和留白代替外框及静态阴影。原一屏布局中部分透明边框保留尺寸占位，不再绘制包围线。
- 登录页与欢迎页去掉暖色基底、深色结构区、渐变标题及装饰循环。保留绿色品牌、黑色操作按钮，以及行情和走势图业务色。小号文字适度放大、加深，保持浅底上的可读性。

## 排版和交互

- `Prose.tsx` / `utils/prose.ts`：通过 React 渲染保护正文、标题末尾的两个汉字及尾随标点，保留真实文本和引用焦点；不改写输入、数值、代码或 URL。静态页直接使用相同的尾部行内标记，无 JavaScript 时仍然可读。
- 数字、日期和表单值使用 `tabular-nums lining-nums`；主内容容器撑满宽度，保留正文阅读宽度和原有响应式布局。
- `ShellNavigation.tsx`：高亮背景以 140ms 移动，导航文字的几何位置与字重保持稳定。
- `chartInteraction.ts` / `LazyECharts.tsx`：统一实时 dataZoom、零节流、关闭插值动画；保留原曲线、数据范围、图例与提示框。取消触摸或失焦时结束现有拖动，卸载时清理事件和图表实例。
- `ParameterSlider.tsx`：继续使用 Ant Design 的步长、键盘和受控值；补齐 touchcancel / pointercancel / blur 生命周期。滑块位置不做 CSS 插值。
- `StreamingMarkdown.tsx` / `chat.css`：仅新增流式字符使用约 140ms 模糊到清晰，常规错开约 20ms，大块文本继续压缩延迟以避免积压。历史回复不重播。
- 复制按钮保留 180ms、最高 1.04 倍的小回弹；成功对勾仍在 2500ms 后消失。减少动态效果模式关闭装饰位移、模糊与回弹，保留清晰内容及任务加载提示。
